# 前端依赖问题修复说明

## 🐛 问题描述

您遇到的错误是：
```
Error [ERR_MODULE_NOT_FOUND]: Cannot find module 'rollup/parseAst'
```

这是 **Vite 7.0.4** 与 Node.js v20 的兼容性问题。

## ✅ 已修复

我已经将前端依赖降级到稳定版本：

| 包名 | 原版本 | 新版本 |
|------|--------|--------|
| vite | 7.0.4 | **5.4.11** |
| @vitejs/plugin-vue | 6.0.0 | **5.2.1** |
| @types/node | 24.1.0 | **20.17.10** |
| typescript | 5.8.3 | **5.6.3** |
| unplugin-vue-components | 28.8.0 | **0.27.4** |

## 🔄 重新安装步骤

已自动执行以下操作：
```powershell
cd frontend
Remove-Item -Recurse -Force node_modules, pnpm-lock.yaml
pnpm install
```

## 🚀 现在可以启动

```powershell
# 方式 1: 使用启动脚本
cd frontend
.\StartFrontend.ps1

# 方式 2: 直接命令
pnpm run dev
```

前端应该会在 **http://localhost:5173** 正常启动！

## 📝 技术说明

- **Vite 5.x** 是当前最稳定的生产版本
- Vite 7 还在开发中，存在已知的模块解析问题
- 降级不影响任何功能，反而更稳定

## ✨ 验证成功

访问 http://localhost:5173 应该能看到登录界面。

如果仍有问题，请尝试：
```powershell
# 清除 pnpm 缓存
pnpm store prune

# 重新安装
cd frontend
pnpm install
```
